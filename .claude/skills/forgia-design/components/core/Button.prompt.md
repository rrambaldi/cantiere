Pulsante d'azione; il primario giallo va usato una sola volta per vista.
```jsx
<Button>Chiudi cantiere</Button>
<Button variant="secondario">Sospendi</Button>
<Button variant="fantasma" size="sm">Annulla</Button>
<Button variant="secondario" mono>/forgia nome</Button>
```
Varianti: primario · secondario · fantasma. Taglie: sm (28) · md (36).
